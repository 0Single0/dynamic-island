# 灵动岛边缘吸附拖拽 + 点击穿透修复

## 目标

1. 修复拖拽后点击穿透失步（拖走后点不了岛）的 bug。
2. 岛体可按住拖拽，只能停靠在当前显示器「顶部居中 / 左边竖排 / 右边竖排」三个位置；松手吸附。
3. 左右停靠时胶囊变竖排（44×300），展开面板朝屏幕内侧展开；顶部时保持现状。
4. 记住停靠位置（localStorage），重启恢复；多显示器下按窗口当前所在显示器计算边界。

## 核心思路

窗口仍是固定的 812×512 透明矩形（不改 tauri.conf.json），岛体在窗口内**按停靠边对齐摆放**：顶停靠时窗口顶部贴屏幕顶、岛水平居中；左停靠时窗口左缘贴屏幕左缘、岛垂直居中；右停靠同理。展开面板永远在窗口矩形内朝屏幕内侧展开，窗口位置在拖拽/停靠切换时做边界钳制即可。

## 改动清单

### 1. 修复点击穿透（src-tauri/src/commands/window.rs）

- `set_island_rect` 改为只存**视口内逻辑偏移**（x/y/w/h 四个 AtomicI32 或仍打包 i64），不再读 `outer_position` 换算绝对坐标。
- `spawn_click_through_thread` 轮询时每帧用 `window.outer_position()` 实时取窗口位置 + 视口偏移 + scale_factor 现算岛体屏幕矩形再判定穿透。窗口无论被拖到哪都不会失步（根因修复）。
- 注意打包格式：改用四个 AtomicI32（x, y, w, h，逻辑坐标），初始化 0 表示未上报。

### 2. 拖拽实现（前端，替换 data-tauri-drag-region）

- `Island.tsx`：胶囊整体和展开态顶栏绑定自定义 pointer 拖拽：
  - pointerdown 记录起点，移动超过 4px 阈值才进入拖拽（避免和「点击展开」冲突）；拖拽中阻止 click。
  - 拖拽用 `getCurrentWindow().setPosition(PhysicalPosition)`（@tauri-apps/api 已有），rAF 节流；岛体跟随窗口整体移动（窗口动 = 岛动，无需逐帧重算 webview 布局）。
  - 松手时吸附：取岛中心所在显示器（`currentMonitor()`），按中心点到上/左/右三边最近距离选边，沿边偏移钳制到显示器边界内（留 8px 边距），调用新 Rust 命令落位。
- 拖拽期间维持窗口可点（不穿透）由第 1 步的实时计算天然保证。

### 3. Rust 新命令（src-tauri/src/commands/window.rs + lib.rs 注册）

- `dock_island(edge: String, offset: f64, margin_top: f64)`：按当前显示器物理边界计算窗口位置并 `set_position`（含钳制）。顶：x=屏中-w/2，y=屏顶；左：x=屏左，y=屏中-h/2+offset；右：x=屏右-w。
- `get_island_monitor()`：返回当前显示器原点/尺寸（逻辑像素），供前端吸附计算与钳制（也可直接用 JS `currentMonitor()`，Rust 侧留一个兜底命令，实现时以 JS API 可用为准）。
- `positionWindow`（`pin_to_top_center`）保留作为默认顶部位。

### 4. 布局与朝向（src/config/island.ts + Island.tsx）

- `config/island.ts` 新增 `type DockEdge = "top" | "left" | "right"`、竖排胶囊尺寸 `COMPACT_SIZE_VERTICAL = 44×300`、边距常量。
- `Island.tsx`：
  - 读 localStorage（key 如 `island.dock.v1`：edge + 沿边偏移比例）；初始渲染即按 dock 摆放容器（顶: justify-center items-start；左: justify-start items-center；右: justify-end items-center）。
  - 紧凑胶囊在 left/right 时宽高对调（motion.div animate 用竖排尺寸），compact 内容层 flex 方向改列，图标竖排。
  - 展开态尺寸不变（都在窗口 812×512 容纳范围内），窗口内对齐方向随 dock 变化，视觉上即「朝屏幕内侧展开」。
  - hover 缩放、弹簧动画逻辑不动；`reportRect` 逻辑不变（仍上报视口坐标）。
- 拖出的新逻辑放独立文件 `src/components/island/useIslandDrag.ts`（hook，含 pointer 状态机 + 吸附计算 + 持久化），Island.tsx 保持 <1000 行。

### 5. 多显示器

- 吸附、钳制一律基于「松手时窗口所在显示器」（JS `currentMonitor()`，fallback Rust 命令）的边界；跨屏拖拽后自动重新计算三边。屏间切换时若原边不存在（如拖到副屏）按最近边吸附。

## 验证

- `pnpm typecheck`、`pnpm build`、`cd src-tauri && cargo check`。
- 手动场景（用户跑 `pnpm tauri dev`）：拖到左/右/顶松手吸附且方向切换；拖拽后立即点击岛体可响应（穿透修复）；展开面板朝屏幕内；重启恢复位置；顶/左/右展开各 widget（ai xl、clock md、music lg）不超出屏幕。
