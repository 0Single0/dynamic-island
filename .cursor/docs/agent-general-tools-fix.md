# 通用 Agent 提示词与工具接入修复

## 原因与证据

原系统提示词没有包含「网易云」或 `netease`，但此前生产 `model_tools()` 只返回音乐读取工具；界面显示的插件列表不等于实际发给模型的工具。因此助手倾向于介绍音乐读取能力，要求启动应用时也没有对应操作。另一个问题是文件、网络和电脑插件只有清单，没有生产执行后端。

参考 DSH 的 `packages/core/system-prompt/src/index.ts`、`docs/subsystems/system-prompt.zh.md`：助手身份、通用规则和工具定义分别维护，工具提供方只贡献本次真实可用的 schema，不把某个插件能力写成助手身份。

## 本次改动

- `model.rs`：通用桌面助手身份，不含任何具体插件名称。普通问候直接回答，不罗列插件、不读取无关本机信息；工具定义不是任务指令，能力以当前注册项为准，不伪造结果。
- `tools.rs`：模型工具由真实执行器支持项筛选，不再硬编码「只开放音乐读取」。保留合法外部函数名映射和严格参数校验。
- `builtin_executor.rs`：共用的工具执行与宿主接口。网易云启动现在使用 `netease.start_or_connect`，播放/暂停/切歌/跳转使用同一 `netease.*` 插件命名空间并逐次确认；通用工具由 `general_tools.rs` 接入文件选择/新建文本、真实搜索、Markdown PDF 和 Windows UIA（Windows 官方界面自动化）服务。
- `plugins/files.rs`：文件读取只允许用户在原生选择框中明确选择的 UTF-8 文本；新建文本先确认内容，再由用户通过另存为选择路径，只创建、不覆盖，限制大小并拒绝网络路径、符号链接和二进制内容。
- `plugins/web_search.rs`：支持设置中心选择的 Bing RSS 或 SearXNG JSON；未配置时返回明确错误，不使用 Mock 结果。网页读取只允许公开 HTTPS，做 DNS、重定向、响应大小和内容类型限制，外部内容标记为不可信。
- `computer/`：使用 UIA 短期 windowId/elementId，执行前重新验证窗口、进程、控件身份和受保护目标；Invoke/SetValue 每次确认，不使用 DLL 注入、任意脚本或静默坐标点击。
- `native_trace.rs` 和手动内置工具命令共用执行器；仍按实际顺序记录工具参数、结果及后续回答。
- `netease.start_or_connect` 不接受程序路径或 shell 命令。使用已有网易云启动器，开始前弹出原生确认，明确说明同步使用本机 9222 调试端口。
- 用户拒绝后，本次运行不再弹出同类确认；取消运行后不执行启动。旧的写操作审批机制未移除。
- 网易云启动工具不自动终止/重启普通模式客户端，返回 `RESTART_REQUIRED`。页面就绪后请求后台同步，不把永久轮询放在工具返回路径中。
- 系统插件元数据与真实工具名对齐，修正音乐状态工具旧别名。

## 验证

本地测试捕获生产适配器的实际 HTTP 请求，确认通用 system 正文和三个工具均进入请求；system 正文没有网易云名称。执行器测试验证工具定义与实现一致、额外参数被拒绝、未确认/已取消不启动、拒绝后不重复请求确认。

真实供应商回归命令：

```powershell
cd E:\code\dynamic-island\src-tauri
cargo test live_ark_general_agent_behavior -- --ignored --nocapture
```

使用现有两个启用的火山方舟模型进行测试，密钥仅从系统凭据库读取；没有打印密钥，也没有发送真实聊天记录或播放数据。工具执行使用明确标记的模拟执行器，不启动真实应用。

| 模型 | 输入 | 实际工具调用 | 回答/结果 |
| --- | --- | --- | --- |
| deepseek-v4.1-flash | 你好 | 无 | 你好！有什么我可以帮你的吗？ |
| glm-5.3-flash | 你好 | 无 | 你好！有什么我可以帮你的吗？ |
| deepseek-v4.1-flash | 你帮我启动下网易云 | 仅 `netease.start_or_connect` | 模拟拒绝后如实说明没有启动，不重试。 |
| glm-5.3-flash | 你帮我启动下网易云 | 仅 `netease.start_or_connect` | 模拟拒绝后如实说明没有启动，不重试。 |

上述真实请求回归通过。原生确认窗口、真实进程启动与后台同步仍需桌面端实际验收；不能把模拟工具测试当作真实启动成功。

## 能力边界

通用身份不等于无条件控制整台电脑。当前已接入的是受限 MVP：文件需要用户选择/另存为，搜索需要先配置后端，电脑只开放 UIA 窗口检查、文本读取、Invoke 和 Value 操作，并逐次确认；Markdown PDF 也需要确认和原生保存对话框；不开放 Shell、任意应用启动、浏览器登录/提交、管理员窗口和密码框。SendInput、截图/OCR、浏览器 CDP、已有文件 Diff/备份/撤销仍待后续任务。已有历史中的旧回答不会被改写，建议用新对话验证通用工具行为。
