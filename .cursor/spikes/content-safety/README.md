# 外部内容、提示词注入和 SSRF Spike

日期：2026-09-29  
关联计划：`PLAN-00-09`

内容边界已落在 `agent::security`：网页、搜索结果、文件、剪贴板和截图内容进入上下文时标记为 `UntrustedContent`，不能覆盖系统/用户策略；供应商 URL 默认 HTTPS，HTTP 仅允许 localhost，拒绝 URL 内嵌凭据和字面量私有/环回地址。

这不是完整 SSRF 防护。真实网络客户端还必须限制重定向、解析每个 DNS 结果、避免 DNS rebinding（域名解析重绑定）、限制响应大小和下载目录，并在浏览器导航与上传下载链路重复执行策略。高风险动作仍需审批。
