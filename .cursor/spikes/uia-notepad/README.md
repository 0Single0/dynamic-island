# UIA 记事本 Spike

日期：2026-09-29  
关联计划：`PLAN-00-05`

UIA（Windows UI Automation，Windows 官方桌面 UI 自动化框架）应作为标准 Windows 应用的优先自动化层；模型只得到短期 `windowId` / `elementId`，不接触 COM 指针。每次操作前重新确认窗口存在、元素仍属于目标窗口，并检查控件模式和窗口完整性级别。

## 最小验收流程

1. 启动一个隔离的记事本测试实例。
2. 读取窗口标题、边界和控件树，找到编辑控件。
3. 读取编辑控件文本，执行 `ValuePattern.SetValue` 设置测试文本。
4. 再次读取文本并确认值一致。
5. 关闭测试实例，确认没有触碰用户已有窗口。

本轮已核对 UIA 的实施边界和安全策略，但当前桌面操作连接没有提供稳定可识别的隔离测试窗口，因此没有把“已完成 UIA 实际读写”写成通过；该条保持待补实机验收，避免虚报。后续应在 Windows runner 上加入专门的 UIA 集成测试。
